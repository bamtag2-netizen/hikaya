# ✒️ حكاية الأقلام

لعبة كتابة جماعية: يبدأ كاتب القصة، ثم ينتقل القلم **عشوائيًا** إلى كاتب آخر، حتى يكتب الجميع فصولهم. بعدها يقترح المشاركون اسمًا للقصة ويصوّتون، ثم يحصلون على رواية PDF منسّقة بغلاف يحمل اسم القصة وأسماء المؤلفين.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `style.css` | التصميم |
| `app.js` | منطق اللعبة (الدعوة، الأدوار، الكتابة، التصويت) |
| `book.js` | إنشاء الرواية PDF والغلاف |
| `firebase-config.js` | بيانات مشروع Firebase (تعدّلها أنت) |
| `firestore.rules` | قواعد حماية قاعدة البيانات |

كل الملفات يجب أن تكون في **نفس المجلد**.

---

## الخطوة ١: إنشاء قاعدة البيانات (Firebase) — مجانًا

GitHub يستضيف الصفحات فقط، لذلك نحتاج مكانًا مشتركًا يحفظ اللاعبين والفصول. Firebase مجاني لهذا الاستخدام.

1. ادخل إلى https://console.firebase.google.com وسجّل بحساب Google.
2. اضغط **Create a project** (أو Add project)، اختر أي اسم، ويمكنك إيقاف Google Analytics.
3. من القائمة: **Build ← Authentication ← Get started**، ثم تبويب **Sign-in method**، وفعّل **Anonymous**.
4. من القائمة: **Build ← Firestore Database ← Create database**، اختر أقرب موقع، وابدأ بـ **production mode**.
5. في Firestore افتح تبويب **Rules**، احذف ما فيه والصق محتوى ملف `firestore.rules`، ثم **Publish**.
6. اضغط على الترس ⚙️ ← **Project settings**، وفي أسفل الصفحة اضغط أيقونة الويب `</>` لإضافة تطبيق ويب، وأعطه اسمًا.
7. سيظهر لك كود فيه `firebaseConfig`. انسخ القيم وضعها في ملف `firebase-config.js` مكان `YOUR_...`.

## الخطوة ٢: الرفع على GitHub

1. أنشئ مستودعًا جديدًا (Repository) عامًا، مثلًا باسم `hikaya`.
2. ارفع الملفات الستة (من Acode عبر Git، أو من موقع GitHub: **Add file ← Upload files**).
3. من المستودع: **Settings ← Pages**، واختر **Branch: main** والمجلد **/ (root)** ثم **Save**.
4. بعد دقيقة سيظهر رابط موقعك، مثل: `https://اسمك.github.io/hikaya/`

## الخطوة ٣: السماح لموقعك بالدخول

في Firebase: **Authentication ← Settings ← Authorized domains ← Add domain**، وأضف: `اسمك.github.io`

انتهى! افتح الرابط وابدأ أول حكاية.

## طريقة اللعب

1. **صاحب الدعوة** يكتب اسمه ويحدد: عدد الكتّاب، عدد الصفحات لكل كاتب، وعدد الأيام لكل دور.
2. يرسل **رابط الدعوة** (نسخ أو واتساب).
3. كل من يفتح الرابط **يسجّل اسمه** (حقيقيًا أو مستعارًا).
4. عند **اكتمال العدد** يظهر لصاحب الدعوة زر البدء، فيكتب الفصل الأول.
5. لكل كاتب **خانة لعنوان الفصل** ومساحة كتابة بعدد الصفحات المحدد (كل **١٥ سطرًا = صفحة**)، ولا يمكن تجاوزها.
6. زر **«حفظ»** يحفظ المسودة، وزر **«تم»** يسلّم الفصل وينقل القلم **عشوائيًا** لكاتب لم يكتب بعد.
7. بعد آخر فصل: يقترح كل كاتب اسمًا ويصوّت، ثم يعتمد صاحب الدعوة الاسم الفائز.
8. تظهر الرواية مع زر **«تحميل الرواية PDF»**: غلاف فيه اسم القصة وأسماء المؤلفين، وصفحة أولى بأسماء المؤلفين، ثم الفصول.

### ملاحظات
- إذا انتهت مهلة كاتب، يظهر لصاحب الدعوة زر **«تجاوز»** لينتقل القلم لغيره.
- يستطيع صاحب الدعوة البدء بالموجودين إذا لم يكتمل العدد.
- هوية كل لاعب مرتبطة بالمتصفح والجهاز الذي انضم منه، فعليه أن يكتب من نفس الجهاز والمتصفح.
